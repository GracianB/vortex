# Guía breve de interacción

| Entrada | Acción |
| --- | --- |
| Puntero | Dirige el campo |
| Mantener pulsado y arrastrar | Aplica fuerza al entorno |
| `1` `2` `3` `4` | Vórtice, Flujo, Órbita, Onda |
| `Espacio` | Pulso |
| `I` | Abrir/cerrar instrumento avanzado |
| `H` | Alternar interfaz y lienzo puro |
| `F` | Pantalla completa |
| `C` | Limpiar estelas |
| `R` | Reiniciar partículas |
| `S` | Guardar captura PNG |
| `M` | Activar o silenciar audio |

El panel controla energía, densidad, estelas, movimiento, color y fondo. Los **seis estados maestros** son Void, Aurora, Solar, Ember, Ice y Paper.

### Accesibilidad y rendimiento

- En móvil el control táctil debe seguir disponible sin exigir teclado físico.
- El sistema considera la preferencia de movimiento reducido y los límites de dispositivo.
- El audio no se inicia de forma obligatoria.
- Si WebGL no está disponible, se muestra un estado de fallo comprensible. No se debe describir un lienzo en blanco como experiencia cargada.
- Compartir guarda ajustes de escena; no es una cuenta ni almacén de sesiones de terceros.
