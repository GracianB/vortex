## Qué es

El segundo prototipo live del mundo **PLAY**: un campo de partículas WebGL. El cursor es la fuerza. Mantén pulsado para inyectar energía.

### 👉 [**Abrir Vórtice →**](https://vortex-gilt-xi.vercel.app/)

Audio de práctica: [Sustained Focus (Suno)](https://suno.com/s/Zq81WeM02AVZnhuC) · el mismo pulso que en el yoga instructor.

---

## Campos

| Modo | Qué hace |
|:-----|:---------|
| **Vórtice** | El campo gira hacia el puntero |
| **Flujo** | Corriente que sigue el gesto |
| **Órbita** | Las muestras rodean el cursor |
| **Onda** | Pulso que se expande |

Paletas: Espectro · Aurora · Brasa · Hielo · Plata.  
Fondos: Vacío · Tinta · Abismo · Pizarra · Niebla · Papel.

---

## Controles

| | |
|:--|:--|
| Puntero | Deforma el campo |
| Clic / hold | Inyecta energía |
| `C` | Borra estelas |
| `R` | Reinicia |
| `S` | Descarga una captura PNG |

Ajusta muestras, energía, estela, paleta y fondo en el panel.
